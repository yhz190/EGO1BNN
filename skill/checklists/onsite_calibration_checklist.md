# 现场标定与录制检查清单

## 一、环境与采集
- [ ] 场地光位固定：关窗帘/开顶灯或双灯对称补光，避免单侧阴影与反光
- [ ] 相机与支架固定，AE/AWB 锁定，采集与演示保持同一光位
- [ ] 背景哑光、无文字/折痕/高反光；只出现一只手
- [ ] 采集协议：类别**交错**采集（每轮 4 类各若干帧，≥4 轮），避免"类别↔时间/光照"混杂
- [ ] junk 类包含无手/半手/远手/物体等难负样本（≥30%）
- [ ] 每类帧数 ≥40（推荐 40~60），记录采集起止时间

## 二、训练与门禁
- [ ] 现场标定训练：`onsite_train_aug.py`（自动 G4：float==Q6 逐帧一致）
- [ ] 会话留出准确率 ≥90%；单标量 1-NN 探针 ≤60%（防止模型只学"手大小/位置"）
- [ ] 权重 blob 行数 = 271，gen_weights 输出 PASS

## 三、部署与板端验证
- [ ] `deploy_onsite.ps1 -BlobDir <blob> -Ckpt <ckpt>` 重建并烧录
- [ ] 板端自检：`record_board_evidence.cmd` 显示 `371/371 frames match the model exactly`
- [ ] 现场试录 1 分钟：4 类手势各停 2~3 秒，类别正确、无整片坍缩

## 四、录制前后
- [ ] 录制分辨率/窗口大小固定，OBS/录屏参数固定
- [ ] 板子保持供电（JTAG 配置掉电丢失，断电后需重新烧录）
- [ ] 录制中保持灯光/机位不动；如需变更，重新标定后再录
- [ ] 留 2 秒空场景参考帧，便于复盘光照

## 五、失败处置
- [ ] WARN（留出 80~90%）：补采 10 分钟并按清单重跑
- [ ] FAIL（<80%）：检查场景一致性/手位/光照，重采后重训
- [ ] 板端自检不一致：先查 CRC/串口，再查 blob 与 bitstream 是否同一版本
