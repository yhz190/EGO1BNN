# B6 会话标定与最终部署（2026-11-01 16:00）

> 背景：B6 是用户 15:41~15:49 新增的大会话（**899 帧**，rock 200 / paper 200 / scissors 199 / junk 300）。
> 域探针显示 **B6 与 B5 不是同一环境**（B5 模型对 B6 零样本 0%，B5↔B6 互测 0.39/0.52）——
> 说明采集设置变了。B6 数据量更大、配比更好，**按协议在 B6 内重新标定**。

live×4 过采样 + 全部 RPS，lr 3e-5，24 epoch；epoch 只看 val；TEST 只评估一次。

## 4. 结论与局限

1. **B6 环境是当前最佳演示环境**：数据 899 帧（配比近 2:2:2:3）、会话内高度一致（val 1.000）、
   T1b 98.89% ± 0.56、板端逐帧复现；
2. **B5 会话作废**（环境已变，探针判别正确）——保留仅作跨域证据；
3. **跨会话泛化仍不成立**（B5↔B6 0.39~0.54）：这是已知局限，演示必须固定在 B6 环境；
4. 当前板内 bitstream = **B6_DA_s1 模型**，可直接演示。
